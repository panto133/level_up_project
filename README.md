# level_up_project
Project I completed for a job interview for Brezna's Level Up program. It is a web application which implements Typescript, Next.js, React, NestJS, MySQL, Tailwind CSS, and Docker Container while the project was done in Microservice Architecture. The point of the application is to unify information from 3 providers with specific mapping.
For the specific documentation and instructions, you can check the PDF files in the root folder. There are also extensive comments explaining the functions and the files which are created in the project itself.
